共同規則

D302、D303、D008。寫在 exchange/doc.go。

  • adapter 是 codec。它把意圖編成位元組，把位元組編成事件。不連線、不讀時鐘、不 sleep、不起 goroutine、不重試。需要簽名時間的方法由呼叫者傳入 now。公開 REST 不簽名，不帶 now。
  • 介面裡沒有 coder/websocket、fasthttp、sonic 的型別。前兩個只在 worker 與 exchange/transport。JSON 用 exchange/internal/codec 的兩份凍結設定：websocket 不複製字串，REST 複製字串。
  • 緩衝區是 worker 的，借給 adapter。交給 Decode 或 Parse 的位元組只在該次呼叫有效。Sink 收到的指標與其中的字串也只在回呼期間有效，要留的自己複製。
  • 數字是 float64。缺值是 decimal.Absent（NaN）。不用 == 比較。寫給交易所時用 decimal.Append：對齊 step、不帶指數。簽過名的 body 只 marshal 一次，簽的和送的是同一份位元組。
  • 時間是 int64 Unix 奈秒，欄位以 Ns 結尾。adapter 只填交易所自己的時間 ExchTsNs。收到的時間由 worker 蓋。
  • 進去的商品是解析好的 *symbol.Info。出來的是 symbol.ExchKey（venue、category、交易所拼法）。adapter 不呼叫 SYM。系統內部的身分是 Info.UID。
  • Fill.FillID 是交易所的 trade id。私有串流與 History 必須相同，資料庫以 (api_id, fill_id) 去重。
  • 憑證、listenKey、簽名不得出現在 log。Credentials、HTTPRequest、HTTPResponse、Dial 的 String、Format、MarshalJSON 都會遮罩。

註冊

exchange/registry.go。D301、D006。啟動時由 exchange/all.Registry() 收集各家 Declare()，不靠 init()。

venue 與帳號種類是兩個 enum，名稱可以相同，不能互查。venue 是市場，UniversalTicker 的第一段。帳號種類是一個 api_id 用哪種憑證、能交易哪些 venue。

例子掛什麼
VenueBinance、BinanceUM、BinanceCM、BinanceEO、Bybit、OkxMarket、PublicREST。任一可為 nil。
AccountKind上面那些，再加上 BinancePMAccountFactory、HistoryFactory、KeyTypes、Passphrase、Trades

BinancePM 是帳號種類，不是 venue。它交易 Binance_Spot_*、BinanceUM_*、BinanceCM_*，每筆請求依 ticker 的 venue 選端點。沒有 BinancePM_* ticker。worker 在 Submit 前用 AccountKind.CanTrade 檢查，不在清單裡就以 1xx 拒絕。

一期實作的 category 是 Spot、Perp、Future：Binance 現貨，BinanceUM 的永續與季度，Bybit 的現貨與 linear，OKX 的現貨與 USDT 本位 SWAP、FUTURES。BinanceCM、BinanceEO、BinancePM 的方法維持宣告並回 ErrNotImplemented。Option 與 Inverse 不在一期。

MD

Market

一個 venue 的公開 websocket。規劃那一半是純函式。連線那一半由 conn worker 用。同一份實例可並發呼叫規劃方法；Session 不可並發。

Topics() []TopicCaps

這個 venue 推哪些平台 topic。表上沒有的就是不支援。TopicCaps.Absent 列出這個 venue 永不填的事件欄位。

Atom(topic Topic, inst *symbol.Info) (AtomRef, error)

一個 feed 對到一個 atom：AtomRef{Route, Channel}。atom id 是 <venue>:<route>:<channel>。route 是身分的一部分，因為同一個 channel 字串可以出現在不同路徑上（Bybit 現貨與 linear 的 publicTrade.BTCUSDT）。多個 topic 可以落在同一個 atom。不推這個 topic 時回 ErrUnsupported，lease 項目變成 REJECTED，只能查的值改走 md.fetch。

Routes() []string

公開路徑。只有一條路徑的 venue 回 []string{RouteDefault}，RouteDefault 是 "default"。

Budget(route string) int

一條連線能裝多少。<= 0 表示交易所不設上限。新 atom 放進同一個 (venue, route) 裡還有空間、n 最小的連線；都滿了才開 n+1。

Cost(channel string) int

一個 channel 佔多少預算。Binance 以 stream 計（cost 1、budget 1024）。Bybit 以訂閱參數的總長度計。

Endpoint(route, override string) (string, error)

這條 route 的 websocket URL。override 是 mdctl.InitPayload.url，空字串用預設 host。override 必須仍是同一家交易所。

NewSession(route string) (Session, error)

一條連線的 codec 狀態。一條 websocket 一份，由讀取迴圈獨佔。

Book(channel string) (BookSync, bool)

這個 channel 的訂單簿序號規則。不帶訂單簿時第二個回傳值是 false。

平台 topic：bestquote、trade、aggtrade、orderbook、orderbook_delta、ticker、liquidation、funding_rate、open_interest、greeks、mark_price。K 線的區間寫在 topic 裡，kline_ 加正規區間，例如 kline_1m。topic 不能含 .，它是 NATS subject 的一個 token。

Session

Limits() SessionLimits

一條連線的規則：每則訂閱的 channel 數與位元組長度（0 表示不限）、送出訊息的 RateLimit、keepalive、交易所主動斷線的 MaxLifetime（0 表示沒有）、ReadLimit。讀取上限必填，websocket 傳輸沒有預設。

Subscribe(channels []string) ([]Request, error) Unsubscribe(channels []string) ([]Request, error)

依 Limits 把 channel 拆成多則 Request。每則有 worker 用來對 ack 的 ID、這則涵蓋的 channel、以及要送出的 Frame。節奏由 worker 依 Limits.Rate 控制。

Ping() []byte

每隔 Keepalive.Interval 要送的應用層 ping。交易所自己 ping、或 websocket ping 就夠時，回 nil。

Decode(frame []byte, sink Sink) error

解析一則文字或二進位 frame，每個事件呼叫 sink 一次。一則 frame 可以有多種、多筆事件。frame 只在這次呼叫有效。

Keepalive 有三個欄位：客戶端 ping 間隔（0 表示客戶端不 ping）、交易所是否會 ping 並期待 pong、多久沒有任何 frame 就當連線已死。

BookSync

本地全本與摺疊在 conn worker。adapter 只判斷一筆更新相對序號狀態該怎麼處理。

Snapshot() SnapshotSource

SnapshotREST：先緩衝串流，再打 PublicREST.Depth，丟掉 snapshot 已經涵蓋的更新（Binance）。SnapshotStream：訂閱後的第一則就是全本（OKX、Bybit）。

Depth() int

SnapshotREST 時要向 REST 要的檔數。

Check(last BookSeq, u *BookUpdate) BookVerdict

BookApply 依序套用。BookSkip 已被 snapshot 涵蓋，丟掉。BookResync 有缺口或 checksum 不對，丟掉本地本、重抓、推一個 reset。BookSeq.Valid 在套用第一份 snapshot 之前是 false。

BookUpdate 比 md.v1.OrderBookDelta 多了交易所序號：First（Binance U）、Last（Binance u、OKX seqId、Bybit u）、Prev（Binance futures pu、OKX prevSeqId）、Checksum（OKX 的 crc32，有號 32 位元）、Snapshot。實作 BookChecksum 的 venue，worker 在套用之後呼叫 Verify(bids, asks []Level, u *BookUpdate) bool。Level.Qty == 0 表示刪掉該檔。

PublicREST

公開 REST，可並發。每個方法回一個 Call，呼叫者送出。不簽名。

Listing(c symbol.Category) (Call[Page[symbol.Listing]], error)

一個 category 的全部商品，一頁一個 Call。SYM 用 Collect 讀完；讀一半不能拿來下架。見下一節。

Depth(inst *symbol.Info, limit int) (Call[*BookUpdate], error)

SnapshotREST 的全本。BookUpdate.Snapshot 為真，Last 是交易所的 update id（Binance lastUpdateId）。

Klines(inst *symbol.Info, interval string, endNs int64, limit int) (Call[[]Kline], error) KlinePage() int

已收盤的 K 線，結束於 endNs（0 表示最新），由舊到新，最多 min(limit, KlinePage()) 根。md.fetch 從已拿到的最早一根繼續往回翻。

OpenInterest(inst *symbol.Info) (Call[*OpenInterest], error)

不推送、只能查的持倉量。會推的 venue 回 ErrUnsupported。

Usage(resp *HTTPResponse) []Used

從回應讀出交易所報告的限速用量。沒有就回 nil。節流在 worker。

SYM

SYM 不拿 PublicREST 本身，它拿 Lister：

Listing(ctx context.Context, c symbol.Category) ([]symbol.Listing, error)

一個 category 讀到最後一頁，否則整次失敗。真 venue 是 ListingOver(rest, doer, now)。沒有 Doer 時回 ErrNoTransport。

symbol.Listing 是跨過這條邊界的商品。adapter 填交易所原生欄位，下游不推導幣別。SYM 在 Validate 之前先把資產代碼轉大寫並套別名（目前只有 XBT → BTC），再判斷 quanto，再推 ticker。

欄位adapter 怎麼填
Venue、Category、Base、Quote、ExchTicker身分。現貨的刷新不能因為回應裡沒有永續就把永續下架。
ExpiryCode、ExpiryNsExpiryCode 是交易所 ticker 上的 YYMMDD，不是由 ExpiryNs 算出來的。0 表示不到期。
ContractSize一張的面額。現貨是 0。平台 qty 已經是張數乘這個值。
ContractValueCcyqty 的幣。線性與期權是 base，幣本位是 quote。現貨可以空，SYM 存成 base。
PriceCcy價格、price_tick、權利金的幣。現貨與期貨是 quote。現貨可以空，SYM 存成 quote。
Settle損益結算幣，不是保證金幣。現貨空。既不是 base 也不是 quote 的 quanto 一期不入庫。
Statussymbol.Status。對不上的原生狀態是 UNKNOWN。只有 TRADABLE 可交易。EXPIRED、DELISTED 進終結表，ticker 與 UID 不變。這組列舉在 symbol 裡仍標暫定；sym.proto 已經定案，之後加值是相容變更。
Filters名稱對界限。已知名稱有 price_tick、qty_step、min_qty、max_qty、min_notional、max_notional、min_price、max_price。有這個限制但沒有界限時，值是 NaN。沒有這個限制時，鍵不出現。

InProcessUIDSource 是 Lister 加上一個沒有行為的 InProcessUIDs()。只有 exchangetest.Source 實作它。那種 UID 只活在分配它的行程裡，不能入庫，也不能送到別的行程。真的 adapter 不實作這個介面。

TD

AccountConfig 是建 adapter 的輸入：APIID、Credentials、REST 與串流的 host override、以及 Simulated。override 空著就用預設 host。Simulated 給「同一台 host、靠一個旗標切 demo」的交易所；OKX 會加 x-simulated-trading: 1，其他家忽略。

憑證只有兩種：hmac、ed25519。OKX 另要 passphrase。Secret 是 HMAC secret，或 PEM 編碼的 ed25519 私鑰。憑證只經 worker 的 socketpair，或給 TD agent 建 History，不進環境變數、檔案或 etcd。

Account

一個 api_id 的私有交易面，可並發。每個方法在 now 簽好一個 Call。有 TradeStream 時，下單與撤單走那條 websocket；這裡的 Submit、Cancel 是 REST 退路。一期 Binance 與 Bybit 的單筆下單、撤單走 websocket，OKX 走 REST。

Limits() AccountLimits

ClientOrderIDMaxLen、CancelBatch（1 表示沒有批次撤單）、下單速率。

Submit(now time.Time, req *OrderRequest) (Call[*OrderResult], error)

一筆單。交易所拒絕時 Parse 回 *Reject。請求可能已送出但讀不到回答，是傳輸層的 ErrUnknownOutcome，由私有串流或下一次 recon 判定。OrderRequest 帶解析好的 Info、side、type、TIF、qty 或 quote qty、價格、ReduceOnly、十進位字串的 ClientOrderID，以及原樣轉送的 Params。

Cancel(now time.Time, ref CancelRef) (Call[struct{}], error)

OrderID 與 ClientOrderID 有一個就夠。平台自己的單一定有 client id。

CancelBatch(now time.Time, refs []CancelRef) (Call[[]error], error)

最多 Limits().CancelBatch 筆，一則請求。結果與 ref 一一對應，nil 是成功。Parse 的 error 是整則請求失敗。留在 REST。adapter 不知道 algo_id：worker 先從 OMS 濾出那個 algo 的未完成單，再依上限切塊。

Snapshot(now time.Time) ([]Call[Page[AccountSnapshot]], error)

對帳讀取：未完成單、持倉、餘額。一家交易所可能要多則請求（BinancePM 每個產品一則），每則還可以分頁。worker 跑完再合併。AsOfNs 由 worker 在第一則送出前蓋。

Leverage(now time.Time, inst *symbol.Info) (Call[float64], error)

回答 td.view 的 EnsureLeverage。

NewStream() (PrivateStream, error)

一條私有行情連線的 codec。交易連線已經帶私有事件時（TradeLimits.Events）不開這條。

NewTradeStream() (TradeStream, error)

一條下單連線的 codec。這家或這個 adapter 不下 websocket 單時回 ErrUnsupported，worker 改送 REST。

Usage(resp *HTTPResponse) []Used

與公開 REST 相同。

有死線開關的 venue 另外實作 CancelOnDisconnect：ArmCancelOnDisconnect(now, timeout, insts) (Call[struct{}], error)。帳號級的開關忽略 insts。Binance 的是逐商品。

同步回答是 OrderResult：交易所單號、狀態、交易所時間。之後的狀態走私有串流。OrderUpdate、Fill、Balance、Position 對齊 td.v1，商品用 ExchKey。餘額沒有 prelock，那是 worker 算的。持倉 Size 帶號，負的是空。Fill.ClientOrderID 在交易所沒送時是空字串。流動性是 maker 或 taker。

td.order 仍帶 UniversalTicker。改成 UID 是介面註解裡寫明的後續工作，不在這次定案。

PrivateStream

一條私有 websocket 的 codec，不可並發。

Prepare(now time.Time) (*Call[string], error)

連線前必須先打的 REST（Binance 建立 listenKey）。結果是 Dial 用的 token。不需要時回 nil（OKX、Bybit）。

Dial(now time.Time, token string) (*Dial, error)

要連的 URL，以及連上後要送的 frame（OKX、Bybit：先登入再訂閱），在 now 簽名。host 是 StreamEndpoint 或預設。Dial.String 只留遮罩後的 URL 與 frame 數量。

Refresh(now time.Time) (*Call[struct{}], error)

延長憑證（Binance 的 listenKey），每隔 StreamLimits.RefreshEvery 一次。沒有過期問題時回 nil。

Limits() StreamLimits Ping() []byte Decode(frame []byte, sink AccountSink) error

StreamLimits 含 keepalive、refresh 間隔、MaxLifetime、ReadLimit。

AccountSink：Ready 表示登入與訂閱都完成，worker 接著 recon，然後才再收新單。Expired(reason) 表示交易所故意結束串流，要重連。其餘是 Order、Fill、Balances、Positions。

TradeStream

D303。一條同時送請求、收回答的 websocket。Binance 的 WS API，以及 OKX、Bybit 提供的下單 channel。不可並發。id 屬於 worker，從 1 起，同一條連線不重複。codec 自己的 frame（logon、訂閱）用不會撞號的 id。

Dial(now time.Time) (*Dial, error)

URL 與連上後的 frame：logon；這條連線也帶私有事件時，再加上訂閱。這些 frame 的回答由 codec 自己消化，串流可用時呼叫 Ready。

Limits() TradeLimits

Events 為真時，這條連線也帶私有事件，worker 不再開 PrivateStream。Binance 現貨是這樣。BinanceUM 的 WS API 不帶，另開私有串流。Bybit 的 trade socket 也不帶，訂單狀態仍走 /v5/private。另外有連線上的請求速率、keepalive、MaxLifetime、ReadLimit。

Ping() []byte

同 Session.Ping。

Submit(now time.Time, id uint64, req *OrderRequest) ([]byte, error) Cancel(now time.Time, id uint64, ref CancelRef) ([]byte, error)

把一筆請求編成 frame。Decode 不記得送過什麼：codec 把讀回答需要的資訊寫進交易所的請求 id。Binance 收字串，o17 是下單、c18 是撤單。Bybit 的 reqId 是 worker id 的十進位，回答同時帶回 op。因此斷線後的遲到回答、以及錄下來的 session，都讀得懂。

Decode(frame []byte, sink TradeSink) error

依 id 交回答，帶私有事件時交事件，並交交易所回報的用量。logon 被拒是 ErrAuth。

TradeSink 嵌入 AccountSink，另有 Submitted(id, res, err)、Canceled(id, err)、Used(u)。拒絕的分類與 REST 的 Parse 相同。

Inflight 在同一個套件，是 worker 用的純邏輯，不是 adapter 要實作的介面。它記下已送出的請求與期限。過期或斷線時還沒回答的是 ErrUnknownOutcome。過期之後才到的回答不再當成即時回答，worker 把它當成一則訂單消息。

CancelBatch、Snapshot、Leverage、History 留在 REST。Binance 的 REST 用 ed25519 簽名。

History

D601。TD agent 做補正時建它，不起 account worker。可並發。游標是 job 存的字串，可以活過行程，所以這裡不用 Page.Next。

Traits() HistoryTraits

Descending：頁面由新到舊，確認線要掃到結尾才能前進。ByID：追上進度時可以沿 FromID 而不是時間。MaxWindow：一則請求最寬的時間窗（Binance 期貨 7 天），0 表示不限。Retention：交易所留成交多久。PageLimit：一頁幾筆。

Fills(now time.Time, q FillQuery) (Call[*FillPage], error)

一個商品的一頁成交。範圍是 (api_id, UniversalTicker)，job 解析後傳入 Info。查詢用 Cursor、FromID、或 StartNs 與 EndNs 其中一種。FillPage.Next 空字串表示這次查詢沒有下一頁。

Order(now time.Time, inst *symbol.Info, orderID string) (Call[*OrderUpdate], error)

用交易所單號查一筆。job 對「有成交、訂單表還沒有終態列」的單號各查一次，終態且 filled_qty > 0 才入庫。

Usage(resp *HTTPResponse) []Used

與其他 REST 面相同。

REST 邊界

Call[T] 是一個準備好的 HTTPRequest 加上 Parse(*HTTPResponse) (T, error)。Parse 把交易所的回答分成 *Reject、*RateLimited、ErrAuth，或一份讀不懂的錯誤。

Page[E] 帶這一頁的 Items，以及 Next(now) (Call[Page[E]], error)。沒有下一頁時 Next 是 nil。下一頁在送出當下的 now 重新簽名。

HTTPRequest 的 query 已編碼、需要簽名的 body 已簽好。Cost 宣告這則請求吃哪個桶、吃多少，桶的名字是 adapter 自己的（Binance 的 weight、orders_10s）。Mutates 為真的請求（下單、撤單）送出兩次會改帳戶；傳輸失敗且請求可能已出去時是 ErrUnknownOutcome。

Doer.Do 只有在沒有一份 Parse 讀得了的回答時才回錯誤。可能已送出（逾時、斷線、5xx）包 ErrUnknownOutcome；確定沒送出（撥號失敗）則不包。Lender 是可選的 Doer：Lend 把回應借給回呼，返回後傳輸重用緩衝區。Run 與 Collect 在做得到時走這條。

錯誤

值意思誰處理
ErrNotImplemented方法在，程式還沒寫。一期的 CM、EO、PM 用這個。呼叫者
ErrUnsupported這家交易所沒有這個能力。規劃變成 REJECTED，或改走別的路徑（REST 下單）。
ErrAuth簽名、權限、IP 白名單、過期的 key。不重試。worker 告警。
*Reject交易所拒絕這筆單。Code 在 200–299 是對到平台表的拒絕，否則是交易所自己的碼。Native 永遠留原碼。策略看到 OrderReject 或 CancelReject。
*RateLimited429 或同等回答。RetryAfterMs == 0 表示交易所沒說要等多久。呼叫者決定等不等。

定案會鎖住的事

鎖的是上面這些型別的方法、參數與回傳值，以及跨邊界的 struct 欄位。加一個可選介面、或在既有方法上加一個不破壞呼叫者的行為，要另看是不是相容。沒有工具會擋下一次不相容的 Go 改動，靠的是 review。

  • 必實作：Market、Session、BookSync、PublicREST、Account、PrivateStream、TradeStream、History，以及兩端的 sink。
  • 可選，用型別斷言：BookChecksum、CancelOnDisconnect、Lender。真 adapter 不實作 InProcessUIDSource。
  • Inflight、Run、Collect、ListingOver 是套件函式，給 worker 與 SYM 用，不是每家要實作的方法。
  • symbol.Status 的列舉仍標暫定，但它屬於已經定案的 sym.proto，不在這張介面裡再定一次。
  • 一期不做的 category 與帳號種類維持 ErrNotImplemented 或 ErrUnsupported。那是實作範圍，不是介面缺方法。
